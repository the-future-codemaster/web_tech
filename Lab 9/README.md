# Lab 9: MERN Stack Todo App

**Aim:** To learn and implement the MERN stack based on the provided documentation and convert one of the previous React and Node.js projects into a MERN application.

## File names:

**README.md**: Contains project documentation, instructions on how to run it, and the learning.

**backend/server.js**: The main Node.js and Express script that creates the server, connects to the MongoDB database, and defines the API endpoints for fetching, adding, updating, and deleting tasks.

**backend/models/Todo.js**: Defines the Mongoose schema for the tasks, enabling structured storage of task data in the MongoDB database.

**frontend/src/App.jsx**: The main React component that manages the application state, sends a GET request to fetch existing tasks on mount, and coordinates the smaller components.

**frontend/src/components/TaskForm.jsx**: The component responsible for handling user input and providing the form to add new tasks to the list.

**frontend/src/components/TaskList.jsx & TaskItem.jsx**: Components responsible for mapping through the array of tasks to display them, and providing the interactive buttons for marking tasks as completed or deleting them.
